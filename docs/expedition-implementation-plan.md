# 探索商场（Expedition）当前实现

## 权威范围

本文记录当前可执行原型。旧 Arc、日常委托三选一、照顾自己和旧房间清单均不再是需求来源。项目处于自测阶段，只维护当前存档格式，不做旧存档迁移。

## 一夜流程与事务边界

1. 玩家在中庭购物、合成并提交店主委托。
2. 点击“探索商场”。若白花或伤口任一种达到三个，确认框先给出危险提示；确认进入后先执行死亡判定。
3. 逐条结算已完成的店主委托。每条在自身演出完成时才消耗提交物、应用 Persona/金钱奖励并存档。
4. 进入选门界面并保存检查点。普通情况显示两扇门，Boss 命中时只显示居中的红门。
5. 每晚完成两轮房间；完成第二轮后推进日期、处理日历补货并返回中庭。
6. Boss 任一轮失败会直接结束当晚；两轮全部成功进入 Demo 完成画面。

每次生成门后保存候选、随机状态、当晚已完成轮数、已进入房间和经济房判定。房间内投入、判定和奖励先保存在 UI 草稿；点击离开/收取结果后一次提交。若房间内退出，恢复最近一次选门检查点，因此不能借重启刷新候选，也不会留下半笔事务。

## 当前房间池与门生成

- 挑战：飞船图书城、灰色大厅、生日派对。
- 奖励：家（权重 3）、雨林（权重 1）、复古餐厅（权重 2）。
- 经济：货架打工（内部权重 3）、回收站（内部权重 1）。
- Boss：扫描员。

生成顺序：

1. Boss 只在当晚第二次选门时判定。三个普通挑战每首通一个增加 33% 概率；三个全通时必定出现。命中后跳过普通选门，只生成扫描员。
2. 当晚尚未出现经济房时，以 50% 概率把一个门位替换为经济房；经济房一旦出现，当晚不再判定。货架与回收站内部权重为 3:1。
3. 其余门位按挑战 60% / 奖励 40% 抽取。已首通挑战永久离开挑战池；挑战池为空时回退到奖励池。
4. 同组选门不重复，当晚已经进入的房间不再出现；没有选择的门仍可在后续轮次出现。

未进入过的房间使用白门，悬停显示“通往未知”。进入过后才同时解锁名称和分类颜色：挑战红、奖励蓝、经济灰。Boss 初见即为红色。

## 挑战数据模型

规则不挂在 UI，也不再挂在整个房间上。层级为：

`MallRoomDefinition -> MallChallengeRoundDefinition -> MallChallengeApproachDefinition`

普通挑战各有一轮，Boss 有两轮；每轮固定两个不可撤回的对策。每个对策独立声明：

- 标题、放卡题干、成功/失败文案；
- 必须全部出现的 Type；
- 至少出现一个的 Type 备选组；
- 必须投入的指定 Persona 卡；
- 必须各自至少出现 1 点的 Shape；
- 上述 Shape 的合计阈值；
- 条件满足时用于反馈的主要 Shape。

指定 Persona 只检查那张 Persona 卡是否投入；两张槽中所有卡牌仍共同贡献 Shape 数值。例如“梦游者卡、梦 5”允许梦 1 的梦游者卡加梦 4 的物品通过。

普通物品在提交后无论成功失败都会消耗；Persona 卡不消耗。允许空槽或只放一张提交。病症和信物不能进入挑战槽。

## 判定与反馈

Type、指定 Persona 和每种必需 Shape 的存在性全部满足后，才根据合计差值计算概率：

- 差值小于等于 0：足够了，100%；
- 差值 1：或许可以，50%；
- 差值 2：或许可以，20%；
- 差值大于等于 3，或类别条件不满足：完全不行，0%。

反馈使用四套全局短句（光、泪、梦、眠各有“完全不行／或许可以／足够了”）：

- 某个必需 Shape 为 0 时，优先提示缺失 Shape；
- 都存在但合计不足时，提示当前数值较低的 Shape；
- 已足够时，提示对策预设的主要 Shape。

只有选择后的放卡题干提供隐性规则提示：Type 词语加粗，Shape 对应的能力词按光黄、泪蓝、梦紫、眠粉着色。选项标题、房间介绍、结果和槽位本身不直接展示规则或数值。

## 正式挑战内容

### 飞船图书城

- 跪下加入：必须有梦游者卡，梦合计 5。
- 调查祭坛：必须有书，光合计 5。
- 首通战利品：`concrete_city_vol_2`（《欢迎来到砼城（下半）》）。

### 灰色大厅

- 放一首音乐：必须有磁带，光合计 4。
- 留下聆听：必须有守夜者卡，泪合计 5。
- 首通战利品：`nocturne_published`（夜曲-出版磁带）。

### 生日派对

- 送上礼物：必须有玩具或花；泪、眠都至少 1，合计 4；足够时主要反馈泪。
- 唱生日快乐歌：必须有倦归者卡，眠合计 3。
- 首通战利品：`birthday_cake`。

普通挑战失败获得一道伤口，之后进入当晚下一次选门；成功后该房间永久离开挑战池。

### 扫描员

第一轮：

- 直面扫描：必须有提灯者卡，光合计 6。
- 躲在箱子背后：必须有梦游者卡，梦合计 6。

第一轮成功只播放结果，不翻奖励卡；普通物品在本次 Boss 草稿中已经锁定消耗。继续后清空槽位并进入第二轮的新题干与选项。

第二轮：

- 时间的尸体：必须有倦归者卡，眠合计 6。
- 黄玫瑰的记忆：必须有任意花；眠、梦都至少 1，合计 7；足够时主要反馈梦。

任一轮失败获得伤口并立即结束当晚。两轮成功不翻通用战利品，直接进入地下安全出口的 Demo 结局。

## 奖励、经济与病症

- 家：可放任意普通物品；物品每个高于玩家当前值的 Shape 令对应 Persona +1。
- 复古餐厅：规则同家，但只接受食物或饮料。
- 雨林：只接受已有 Persona 卡，确认后该 Shape +1。
- 三个奖励房空过均获得 20 元；放入卡却没有成长仍照常消耗并产生白花。
- 家/餐厅使用物品获得一朵白花；雨林使用 Persona 获得两朵；空过不获得白花。
- 回收站最多投入三个普通可售物，按记录购买价或定义售价原价回收。
- 货架打工不需要放卡，翻开工资后结算 20 元。

白花和伤口都是无 Shape 的病症，只能进入合成台原料槽。获得一种病症时先抵消一个相反病症。死亡只在开始下一次探索时判定。白花可用光或泪净化，伤口可用眠或梦净化；每次只提高实际采用路径的下一次要求。

## UI 与验证

探索界面隐藏全局边框、Todo List 和右下角头像，保留底部手牌、右上物品说明和左下调试按钮。房间界面为顶部标题、左侧占位图、右侧逐句文字/对策/反馈/槽位。所有玩家文案使用 `zh_CN` 与 `en` 翻译键并支持实时切换。

自动化重点覆盖：门生成与检查点、逐对策条件、指定 Persona 与合计值、多 Shape 动态反馈、概率边界、物品消耗、三件正式战利品、休整/经济房、病症抵消、Boss 两轮中断与完成、运行时本地化和富文本题干。交付前执行导入检查、相关 GUT 和完整 `tools/check.ps1`。
