# 新界面参考素材

本目录保存 2026-08 UI 重构的原始参考素材，不作为 Godot 运行时资源路径。

- `边框-全局.png`：地图、商店与合成台共用的中央画面边框。
- `任务栏-收起.png` / `任务栏-展开.png`：Todo 小票的折叠与展开状态。

- `纸袋.png`：合成台入口。
- `纸牌-透明度90%.png`：所有手牌与槽位牌的底图；按素材本身显示，不再额外降低透明度。
- `对话框-玩具店.png`：玩具店店主对白底图。
- `Back.png` / `Shelf.png` / `Talk.png`：店内导航按钮；中英文界面暂时共用素材上的英文。

运行时使用的文件应复制并改为稳定的英文文件名，存放在 `resources/`；代码不得直接引用本目录。
